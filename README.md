# MeetAura — AI-Powered Meeting Summarizer

> Transform lengthy meeting recordings into clear, structured, and actionable insights with AI.

MeetAura is a full-stack AI-powered meeting assistant that helps users convert meeting audio into **transcripts, summaries, key decisions, and actionable tasks**. It reduces the effort of manually reviewing long recordings and presents the most important information in a simple, organized format.

## 🚀 Live Demo

**Try MeetAura here:**
https://meet-aura-frontend5.vercel.app/

**GitHub Repository:**

## ✨ Features

* 🎧 **Meeting Audio Upload** — Upload meeting recordings for processing.
* 📝 **AI Transcription** — Convert spoken conversations into text.
* 🤖 **AI-Powered Summarization** — Generate concise summaries from lengthy meetings.
* 🎯 **Key Decisions** — Identify important decisions and conclusions.
* ✅ **Action Items** — Extract tasks and responsibilities discussed during meetings.
* 📌 **Structured Insights** — Organize meeting information into clear sections.
* 💻 **Responsive Interface** — Clean and user-friendly interface across different screen sizes.
* ⚡ **Full-Stack Architecture** — Separate frontend and backend for better scalability and maintainability.

## 🧠 How It Works

```text
Meeting Audio
     │
     ▼
Upload Recording
     │
     ▼
Backend Processing
     │
     ▼
AI Transcription
     │
     ▼
AI Analysis
     │
     ├── Summary
     ├── Key Decisions
     └── Action Items
             │
             ▼
       Meeting Insights
```

MeetAura takes the uploaded meeting recording, processes it through the backend, uses AI to understand the conversation, and presents the generated insights to the user.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AkshitaSood915/MeetAura.git
cd MeetAura
```

### 2. Setup the Backend

```bash
cd backend
npm install
```

Create a `.env` file inside the backend directory and add the required environment variables.

```env
PORT=5000
API_KEY=your_api_key
```

Start the backend:

```bash
npm start
```

---

### 3. Setup the Frontend

Open a new terminal:

```bash
cd frontend
npm install
```

Start the development server:

```bash
npm run dev
```

The frontend will then be available at the local URL provided by Vite.

---

## 🔐 Environment Variables

Keep sensitive credentials inside environment variables.

## 💡 Why MeetAura?

Meetings often contain important information that can be difficult to remember or revisit later.

MeetAura simplifies this process by converting conversations into:

**Meeting → Transcript → Summary → Decisions → Action Items**

This allows users to spend less time taking notes and more time focusing on the actual discussion.
